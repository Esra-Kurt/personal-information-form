# Personal Information Form

A simple personal information form built with Python and Tkinter.

## Features
- Enter your name.
- Display a personalized greeting.
- Show a warning when the name field is empty.

## Technologies
- Python
- Tkinter

## How to Run
1. Make sure Python is installed.
2. Run `main.py`.

## Purpose
This project was created to practice Python fundamentals and GUI development.
